# Управление предметами, работами, вариантами и ID

Кнопки в каталоге создаются автоматически из сохранённых материалов. Отдельного редактора кнопок нет. Один материал — один вариант работы с файлом решения и, при необходимости, файлом задания.

## Найти материал

Откройте админку из личного чата бота. В «Материалы» используйте поиск: например, «2 курс математика ДЗ 3» или полный ID. Поиск учитывает название учебного заведения, специальность, курс, семестр, предмет, работу, вариант и код. Условия через пробел могут встречаться в разных частях названия.

В выпадающем списке показан полный путь материала. Под ним тот же путь отображается с переносом строк для телефона. Поиск не сбрасывает изменения в уже открытой форме. Если выбранного материала нет среди результатов поиска, его форма остаётся открытой; выберите другую запись явно.

## Добавить предмет или работу

1. Нажмите «Новый материал».
2. Заполните семь частей ID по схеме ниже.
3. При желании укажите названия учебного заведения и специальности для учёта в админке.
4. Введите курс и семестр так же, как у существующих материалов этого раздела. Подсказки помогают выбрать уже используемые названия.
5. Для нового предмета введите новое название в поле «Предмет». Для новой работы внутри существующего предмета сохраните название предмета и введите новое «Название работы».
6. Заполните «Вариант», описание, доступ, цену при платной выдаче.
7. Выберите файл решения и, если нужен, файл задания.
8. Нажмите «Сохранить материал».

После повторного открытия приложения студент увидит новые кнопки. Раздел появляется, когда в нём сохранён хотя бы один материал. Пустых предметов и работ без вариантов пока нет.

Названия определяют группировку. Например, «Математика» и «Высшая математика» — две разные кнопки. Все варианты одной работы должны иметь одинаковые курс, семестр, предмет и название работы.

## Добавить вариант

1. Найдите и выберите один из вариантов нужной работы.
2. Нажмите «Новый вариант выбранной работы».
3. Общие поля, описание и цены скопируются. Если у исходного материала уже есть структурированный ID, первые шесть частей кода тоже скопируются.
4. Введите код нового варианта и его название, например «06» и «6 вариант». Для исходного материала со старым ID заполните остальные части кода.
5. Выберите файлы: решение и задание очищаются, чтобы случайно не выдать документ от предыдущего варианта.
6. Нажмите «Сохранить материал». Исходный вариант сохранится отдельно.

## Изменить названия

Для одного материала: выберите его, измените поля формы и нажмите «Сохранить материал». Так можно, например, исправить подпись «Вариант 3».

Для целого предмета или работы:
1. Выберите сохранённый материал из нужного раздела.
2. Сохраните изменения формы, если они есть.
3. Ниже откройте блок «Переименовать предмет или работу».
4. Выберите «Предмет со всеми работами» или «Работу со всеми вариантами».
5. Проверьте путь и количество затрагиваемых материалов.
6. Введите новое название и нажмите «Переименовать».

Предмет меняется в рамках выбранных учебного заведения, специальности, курса и семестра. Работа меняется только внутри соответствующего предмета. Другие разделы не затрагиваются. Если раздел с новым названием уже существует в этой области, приложение не объединяет их автоматически и предлагает другое название. ID и ранее оформленные покупки остаются прежними.

## Структура ID

Пример: **0102110304_05**.

| Часть | Значение примера | Длина |
|---|---|---|
| Учебное заведение | 01 | 2 цифры |
| Специальность | 02 | 2 цифры |
| Курс | 1 | 1 цифра |
| Семестр внутри курса | 1 | 1 цифра |
| Предмет | 03 | 2 цифры |
| Работа | 04 | 2 цифры |
| Вариант после _ | 05 | 2 цифры |

Разделение для чтения: **01 02 1 1 03 04 _05**. Сохраняется без пробелов.

Каждая часть вводится отдельно. «3» в поле предмета превращается в «03». Для однозначных частей допустима одна цифра, для двузначных — до двух. Буквы, отрицательные числа и слишком длинные значения не принимаются. Все семь частей обязательны для нового материала. В текущем каталоге семестр обозначается внутри курса: 1 или 2; сквозные номера 10–12 в однозначную часть не помещаются.

Номера учебных заведений, специальностей, предметов и работ назначаете вы. Например, закрепите «01» за своим вузом и «03» за математикой в выбранном разделе. Приложение не угадывает эти номера и не перенумеровывает весь каталог. Для одной работы сохраняйте первые шесть частей, меняйте только номер варианта. Код и текстовые подписи — отдельные поля: проверяйте, что указанные курс, семестр и вариант соответствуют коду.

Одинаковый учётный ID не может быть у двух материалов. Существующая запись не перезапишется при создании нового материала с занятым кодом.

### Что делать со старыми ID

Существующие материалы работают со старыми ID, пока вы не назначите им новый код. Найдите материал, заполните семь частей и сохраните. Можно обновлять их постепенно.

Новый код отображается в списке и поиске админки. Внутренний ключ существующего материала сохраняется: с ним связаны старые покупки, ожидающие оплаты заказы и повторная выдача. При создании нового материала первоначальный внутренний ключ совпадает с его первым учётным ID, но дальнейшая смена учётного ID не меняет этот ключ.

### Учебное заведение и специальность

Их названия и коды сейчас нужны для учёта и поиска в админке. Дизайн и уровни каталога студента остались прежними: курс → семестр → предмет → работа → вариант. Отдельного выбора учебного заведения и специальности в приложении пока нет. Если наполнять каталог для нескольких заведений с одинаковыми названиями разделов, сначала понадобится добавить такой выбор, чтобы материалы не смешивались на экране студента.

## Связь с библиотекой файлов

У каждого файла теперь показан полный путь назначенных материалов, а не только работа и вариант. Кнопки «Выбрать решением» и «Выбрать заданием» заполняют соответствующие поля открытой формы; затем нажмите «Сохранить материал».

Метка «Папка» помогает искать документы. Она не создаёт кнопки предметов и не меняет поля материала.
