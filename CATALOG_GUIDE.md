# Каталог: разделы, работы и варианты

Админка устроена как папки:

**Учебное заведение → специальность → курс → семестр → предмет → работа → вариант.**

На каждой ступени можно создать запись, открыть её, изменить название или удалить. Вводить ID вручную больше не нужно.

## С чего начать

В начальной структуре уже есть **РГУНиГ → РФ**. Откройте админку кнопкой в личном чате бота.

1. Нажмите **РГУНиГ**.
2. Нажмите **РФ**.
3. Откройте нужный курс или нажмите **«Создать: курс»**, введите, например, «1 курс» и нажмите «Создать».
4. Внутри курса откройте или создайте «1 семестр».
5. Внутри семестра создайте предмет, например «Математика».
6. Откройте предмет и создайте работу, например «Самостоятельная №1».
7. Откройте работу и создайте вариант, например «Вариант 1».

После создания раздел открывается автоматически. Для возврата нажмите нужную ступень в строке пути наверху. Пустые разделы можно создавать заранее: файлы для этого не нужны.

## Файлы и цена

Библиотека появляется **только внутри варианта**.

1. Загрузите документы в подключённую группу Telegram или в личный чат бота.
2. Откройте нужный вариант в админке.
3. В библиотеке найдите файл решения и нажмите **«Выбрать решением»**.
4. Если есть отдельный файл условия, нажмите возле него **«Выбрать заданием»**. Если его нет, заполните «Описание задания».
5. Выберите доступ: «Бесплатно» или «Платно».
6. Для платного варианта укажите цену. В форме написано, какой способ оплаты сейчас выбран в приложении. Цену для другого способа можно сохранить заранее.
7. Когда вариант готов к выдаче, снимите галочку **«Временно отключить выдачу и оплату этого варианта»**.
8. Нажмите **«Сохранить вариант»**.

Новый вариант создаётся отключённым и без файлов. Это позволяет спокойно подготовить его до начала выдачи. Условие, решение, описание и цена относятся к выбранному варианту, а не ко всей работе.

Для сохранения рублёвой цены подключение ЮKassa не требуется. Приём платежей через неё включается отдельно по [инструкции обновления](UPDATE_GUIDE.md). Пока для действующего способа оплаты нет цены, платный вариант недоступен для покупки.

Во время сохранения кнопка показывает «Сохраняем…». После подтверждения сервера — «✓ Сохранено», рядом остаётся сообщение. При ошибке введённые данные сохраняются в форме, а причина показывается возле кнопки.

Чтобы добавить ещё один вариант, вернитесь на ступень работы через путь наверху и нажмите «Создать: вариант». Выберите его собственные файлы и цену.

## Изменить название

Возле нужного раздела нажмите **«Изменить»**, либо откройте раздел и нажмите **«Изменить название»**.

Введите новое название и сохраните. Оно обновится и у вложенных материалов. Номер раздела, коды материалов и прежние покупки сохранятся.

Примеры:
- Переименование предмета обновит его название у всех работ этого предмета.
- Переименование работы обновит её название у всех вариантов.
- Переименование варианта изменит только этот вариант.

Внутри одного родителя нельзя создать две новые записи с одинаковым названием. В разных курсах одинаковые предметы допустимы.

## Автоматические ID

Все семь частей состоят из **двух цифр**:

| Ступень | Пример |
|---|---|
| Учебное заведение | 01 |
| Специальность | 01 |
| Курс | 01 |
| Семестр | 01 |
| Предмет | 02 |
| Работа | 03 |
| Вариант | 04 |

Полный ID: **010101010203_04**. Для чтения: **01 01 01 01 02 03 _04**.

Номер выдаётся по порядку создания внутри родительского раздела:
- у первого курса предметы могут иметь номера 01, 02, 03;
- у другого курса, внутри его семестра, предметы снова начинаются с 01;
- у каждой работы свой ряд вариантов 01, 02, 03.

Это порядковые коды записей. Название «Вариант 18» само по себе не назначает код 18: если он создан первым в работе, его порядковый номер будет 01.

Назначенные номера не меняются при переименовании и не сдвигаются после удаления соседей. Удалённые номера повторно не выдаются. В каждом родительском разделе доступно 99 порядковых номеров; если они закончатся, приложение сообщит об этом.

## Удалить

Нажмите **«Удалить»** возле записи или внутри открытого раздела. Приложение покажет название и количество вариантов, которые исчезнут.

Удаление предмета убирает из каталога также все его работы и варианты. Удаление учебного заведения убирает всю его ветку. Если каталог успел измениться после загрузки страницы, потребуется обновить список и повторно проверить удаление.

Заказы и документы в Telegram не удаляются. Ранее оплаченные файлы можно повторно получить командой /purchases или через поддержку. Восстановление удалённой ветки отдельной кнопкой пока не предусмотрено, хотя записи сохраняются в базе для учёта. Для временного отключения одного варианта используйте галочку в его форме.

## Что будет со старыми работами

При первом запуске обновления существующий каталог переносится в структуру автоматически. Курс, семестр, предмет, работа и вариант берутся из прежних названий. Если учебное заведение и специальность не указаны, используется **РГУНиГ → РФ**.

Файлы, описания, цены, отключённые позиции и покупки сохраняются. Работам назначаются новые автоматические коды; старые внутренние ключи остаются связаны с заказами. Повторный запуск приложения не создаёт копии разделов и не возвращает удалённые материалы.

Если в старом каталоге уже были дубли вариантов с одинаковыми названиями, они сохраняются отдельными записями со своими номерами: их можно переименовать или удалить после проверки.

## Что видит студент

Оформление каталога сохранено. Если учебное заведение и специальность одни, приложение сразу показывает курсы. При добавлении нескольких заведений или специальностей появляется выбор соответствующего уровня, чтобы одинаковые названия предметов не смешивались.

Пустые разделы без вариантов пока видны только в админке. Студенческий каталог строится по вариантам. При ознакомлении с работой, содержащей несколько вариантов, студент выбирает вариант задания — бот пришлёт именно его файл или приложение покажет его описание.

## Библиотека и темы Telegram

Темы группы помогают хранить документы в порядке. Они не создают предметы автоматически: разделы каталога создаются в админке.

«Метка для поиска» в библиотеке помогает найти документ по предмету, работе или папке. Она не перемещает сообщение в Telegram. Кнопки выбора решения и задания только подставляют файл в форму; после выбора нажмите «Сохранить вариант».

История заказов и возвраты доступны в раскрывающемся блоке «Заказы и возвраты» внизу админки.
