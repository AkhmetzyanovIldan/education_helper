# Обновление: ЮKassa, заметная выдача и группа файлов

## Что изменилось

Кнопка получения сразу становится зелёной и показывает «Обрабатываем…». Повторные нажатия блокируются. Крупное окно сообщает, что файл придёт в чат, и остаётся до нажатия «Понятно». После успешного запроса повторный заказ этого файла блокируется в текущем окне на минуту. При сетевой ошибке кнопка снова доступна, а повтор использует прежний ключ запроса.

## Подключить ЮKassa для существующего магазина

Это техническая интеграция внешней страницы оплаты. Правила Telegram требуют Stars для цифровых товаров внутри Mini App; переход на внешнюю кассу не отменяет это ограничение. По умолчанию оставлен Stars. Режим ЮKassa включается явной настройкой владельца.
Источник: https://core.telegram.org/bots/payments-stars

1. В Render → Environment добавьте:
   - PAYMENT_PROVIDER = yookassa
   - YOOKASSA_SHOP_ID = Shop ID именно вашего магазина из кабинета ЮKassa.
   - YOOKASSA_SECRET_KEY = секретный ключ API этого магазина.
   - YOOKASSA_TEST_MODE = true для тестового магазина, false для рабочего.
2. BOT_TOKEN, DATABASE_URL, APP_URL, TELEGRAM_WEBHOOK_SECRET оставьте прежними.
3. В кабинете ЮKassa откройте настройку HTTP-уведомлений и укажите:
   https://education-helper.onrender.com/yookassa-webhook
4. Подпишитесь на payment.succeeded, payment.canceled и refund.succeeded.
5. Сохраните настройки и перезапустите Render.
6. В админке откройте каждый платный материал и заполните «Цена в рублях для ЮKassa». Цены Stars сохранены отдельно. Автоматического переноса старых рублёвых цен нет.
7. Проверьте оплату сначала с тестовым магазином и соответствующим тестовым режимом.

Ключи ЮKassa не нужны в BotFather: здесь используется API ЮKassa и внешняя страница оплаты. Не публикуйте ключи в GitHub или сообщениях.

### Как возвращается покупатель

Кнопка открывает страницу ЮKassa. После оплаты «Вернуться в магазин» ведёт в Telegram к вашему боту с номером заказа. При первом открытии такого перехода Telegram может попросить нажать «Начать»: это штатное поведение клиента.

Файл отправляется автоматически после подтверждения платежа сервером. Возврат по ссылке, закрытие страницы или слова клиента «я оплатил» не дают право на файл. Даже если клиент не вернулся из браузера, подтверждённый платёж ставит документ в очередь.

Webhook проверяется повторным запросом к API ЮKassa: сверяются магазин, ID платежа, заказ, сумма, RUB и тестовый/рабочий режим. Повторные события не создают повторную обычную выдачу. Незавершённые известные платежи дополнительно сверяются фоновым обработчиком с интервалом от пяти минут; на спящем Render проверка возобновится после пробуждения. При большой очереди период увеличивается.

Возвраты доступны в админке и кабинете ЮKassa. Поддерживается полный возврат; уведомление о частичном возврате не отзывает доступ автоматически. Если возврат пока обрабатывается, повторите проверку позднее. Уже скачанный документ не удаляется с устройства.

Документация ЮKassa: https://yookassa.ru/developers/using-api/webhooks

### Чеки для самозанятого

Подтверждение оплаты ЮKassa не заменяет чек «Мой налог». Автоматическая регистрация дохода приложением не реализована.
В актуальной инструкции ЮKassa для самозанятых указан ручной выпуск чека: https://yookassa.ru/developers/payment-acceptance/receipts/basics

Чтобы передать готовый чек:
1. Сформируйте чек в «Мой налог» и сохраните его файлом.
2. Возьмите номер заказа из админки.
3. Отправьте файл в личный чат с ботом, в подписи напишите:
   /receipt НОМЕР_ЗАКАЗА
4. Бот передаст чек покупателю этого заказа. Файл с такой подписью не попадёт в библиотеку учебных работ.

При возврате отдельно обработайте чек в «Мой налог». До публичных продаж также остаётся добавить условия покупки и подтверждение согласия: данный механизм ещё не реализован.

## Организовать отдельную группу загрузки

1. С аккаунта @AxmIldan создайте закрытую группу Telegram, например «Файлы приложения».
2. Добавьте туда своего существующего бота.
3. Назначьте бота администратором, чтобы он получал документы в группе. Не добавляйте студентов: группа предназначена для вас и бота.
4. Включите «Темы» в настройках группы. Вложенных папок Telegram не предоставляет: темы можно назвать «1 курс — Математика» и «2 курс — Геофизика».
5. Из своего аккаунта отправьте в группу команду /bind_storage. Анонимное отправление от имени группы не подходит.
6. Дождитесь подтверждения «Группа подключена».
7. Создайте темы и отправляйте туда документы.
8. Откройте админку → «Обновить» → «Библиотека файлов».

Бот не отвечает на каждый документ, чтобы не засорять чат. Документы от других участников, из непривязанных групп и от анонимных отправителей не индексируются. Привязать группу может только уже закреплённый владелец. Если привязать другую группу той же командой, новые загрузки будут приниматься из неё; старые записи библиотеки сохранятся.

Документы, которые были в группе до добавления бота, автоматически не появятся. Их нужно отправить заново. Для доступа к документу темы, созданной до подключения бота, название можно записать вручную в библиотеке или указать в подписи к документу.

## Порядок в библиотеке

- Поиск работает по имени файла и полю «Папка».
- Поле «Папка» заполняется подписью документа, а если подписи нет — названием темы (если бот получил событие создания темы). Например: «1 курс / 1 семестр / Математика / ДЗ 1».
- «Папка» — метка учёта в админке. Она не перемещает Telegram-сообщение и не создаёт вложенные папки в чате.
- Метку можно менять кнопкой «Сохранить папку».
- Под файлом указано, к каким работам/вариантам он назначен, либо «Не назначен материалам».
- «Выбрать решением» и «Выбрать заданием» подставляют файл в форму материала. Затем нажмите «Сохранить материал».
- Страницы библиотеки содержат по 100 файлов; старые файлы доступны через поиск и «Далее».
- Старый способ загрузки в личный чат с ботом продолжает работать.
- Документы не передаются из папки в папку физически: в Neon хранится учёт, в Telegram — сами документы. Google Диск можно оставить для оригиналов/резервных копий.

## Проверки

Автоматические тесты подменяют API Telegram и ЮKassa; реальные платежи при разработке не проводились. После подключения вашего магазина проверьте оплату, отмену, возврат и фактическое получение файла. Новые поля базы добавляются автоматически при запуске без удаления существующих покупок и файлов.
