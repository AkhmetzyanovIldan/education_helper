# Настройка приложения с нуля: GitHub → Neon → Render → Telegram

Обновление от 9 сентября: [ЮKassa, группа загрузки и библиотека файлов](UPDATE_GUIDE.md). Для новых возможностей используйте эту инструкцию; разделы ниже описывают исходный запуск со Stars.

Эта инструкция относится к текущему коду. Уже существующего бота и существующий сервис Render можно оставить. Сейчас документы загружаются через чат бота. Google Диск используется для оригиналов; прямой автоматической загрузки с Диска в приложении пока нет.

## 1. GitHub

Репозиторий: https://github.com/AkhmetzyanovIldan/education_helper

Ветка для Render: main. В неё загружаются программа, интерфейс и инструкции. Файлы студентов и секреты на GitHub загружать не нужно.

Если на Render включён Auto-Deploy, загрузка изменений может сразу запустить сборку. До заполнения новых переменных запуск новой версии завершится ошибкой — после настройки потребуется повторный деплой.

## 2. Создать базу в Neon

1. Откройте https://console.neon.tech и войдите/зарегистрируйтесь.
2. Создайте проект кнопкой New project / Create project.
3. Название: education-helper. Выберите бесплатный план Free.
4. Регион желательно выбрать рядом с регионом вашего сервиса Render. Остальные настройки можно оставить предложенными.
5. В проекте нажмите Connect.
6. Выберите основную ветку и базу проекта. Включённый Connection pooling можно оставить.
7. Скопируйте Connection string — строку, которая начинается с postgresql://. Если показана команда psql, нужна только строка подключения внутри кавычек, без psql и кавычек.
8. Сохраните всю строку в DATABASE_URL на Render на следующем шаге. Не удаляйте параметры после вопросительного знака: они могут включать настройки защищённого соединения.

Эта строка содержит пароль. Не вставляйте её в GitHub, публичные сообщения и скриншоты.

Создавать таблицы и загружать файлы в Neon не нужно. При первом успешном запуске приложение создаст таблицы автоматически. Не удаляйте проект Neon: в нём будут покупки, каталог и права администратора.

Официальная справка: https://neon.com/docs/connect/connect-from-any-app

## 3. Настроить существующий Render

1. Откройте https://dashboard.render.com.
2. Нажмите на существующий сервис вашего приложения.
3. Откройте Settings.
4. Проверьте, что это Web Service с Node.js, репозиторий education_helper, ветка main.
5. Если есть поле Root Directory, оставьте пустым: package.json лежит в корне проекта.
6. Build Command: npm ci --include=dev && npm run build:css
7. Start Command: npm start
8. Health Check Path: /health
9. Сохраните настройки.

Включение dev-зависимостей в сборку нужно для Tailwind. Это не включает тестовый режим приложения.

Официальная справка: https://render.com/docs/deploys

## 4. Заполнить Environment на Render

Внутри того же сервиса откройте Environment → добавление/редактирование Environment Variables.

| Key — название | Value — значение |
|---|---|
| BOT_TOKEN | Токен уже существующего бота. Если он уже указан правильно, оставьте его |
| APP_URL | Адрес сервиса Render с https://, например https://education-helper.onrender.com. Возьмите именно свой адрес из панели сервиса |
| DATABASE_URL | Полная строка подключения, скопированная из Neon |
| TELEGRAM_WEBHOOK_SECRET | Новая случайная строка минимум из 32 латинских букв/цифр |
| ADMIN_USERNAME | AxmIldan — без символа @ |
| NODE_VERSION | 24 |

ADMIN_CHAT_ID можно пока не добавлять: при первом сообщении /start от @AxmIldan бот закрепит его числовой Telegram ID в базе. Если точный собственный числовой ID известен, его можно указать заранее.

PORT обычно задаёт Render, вручную добавлять его не нужно.

Старые YOOKASSA_*, DOWNLOAD_TOKEN_TTL и TELEGRAM_WEBHOOK_URL новой программой не используются. Не путайте TELEGRAM_WEBHOOK_SECRET с BOT_TOKEN: это разные значения.

### Как получить случайную строку TELEGRAM_WEBHOOK_SECRET

На вашем компьютере уже установлен Node.js:
1. Откройте меню «Пуск».
2. Введите cmd и откройте «Командную строку».
3. Вставьте следующую команду и нажмите Enter:

```bat
node -p "require('crypto').randomBytes(32).toString('hex')"
```

4. Скопируйте полученную строку из 64 символов в TELEGRAM_WEBHOOK_SECRET на Render. Это значение не надо отправлять в чат или помещать в код.

Сохраните переменные окружения. Если предложено Save, rebuild, and deploy — выберите его.

Настройка версии Node: https://render.com/docs/node-version

## 5. Запустить приложение

1. Если деплой ещё не начался, выберите Manual Deploy → Deploy latest commit.
2. Откройте Logs / Events и дождитесь успешного запуска.
3. В журнале должна появиться строка Server listening, затем сервис должен оставаться запущенным.
4. Откройте в браузере свой адрес Render с /health на конце. Ожидаемый ответ: {"ok":true}.
5. Откройте основной адрес: должен появиться каталог.

Проверка /health подтверждает работу процесса. Она не проверяет платёж и доставку документа — это проверяется ниже.

## 6. Проверить существующего бота

Если бот уже привязан к тому же адресу Render, заново создавать его не надо. Если адрес поменялся, обновите URL Mini App в BotFather на новый APP_URL.

Сервер сам устанавливает webhook. Вручную открывать URL с токеном бота не нужно. Второй сервер или запущенная на компьютере старая версия того же бота могут мешать: должен работать только один текущий экземпляр.

1. Войдите в Telegram под аккаунтом @AxmIldan.
2. Откройте чат со своим ботом.
3. Отправьте /start.
4. Бот должен показать кнопки «Открыть материалы» и «Админка».
5. Открывайте админку кнопкой внутри Telegram. Обычная вкладка браузера не передаёт подтверждение Telegram-аккаунта.

После первого закрепления прав переименование вашего аккаунта не уберёт права; присвоение прежнего username другому человеку не даст ему доступ.

## 7. Загрузить первый файл

1. Отправьте своему боту небольшой настоящий файл, например PDF. Именно вложение «Файл/Документ», а не ссылку.
2. Фото отправляйте как файл, а не сжатое изображение.
3. Бот подтвердит получение и покажет идентификатор файла. Копировать его вручную не требуется.
4. Нажмите «Админка» → «Обновить».
5. Выберите существующий материал либо «Новый материал».
6. Заполните курс, семестр, предмет, название, вариант и описание.
7. В поле «Файл решения» выберите загруженный документ.
8. Для первой проверки установите «Бесплатно».
9. Нажмите «Сохранить материал».
10. Заново откройте каталог, найдите работу и нажмите «Получить бесплатно».
11. Убедитесь, что документ пришёл в чат и открывается.

Для нового материала поле ID — короткое уникальное имя латиницей/цифрами, например math_1_2. Это внутреннее обозначение: студенту его вводить не надо.

Старые записи с отсутствующими документами отображаются как недоступные. Их надо заполнить через админку.

## 8. Настроить «Ознакомиться с заданием»

Вариант А: заполните описание, а «Файл задания» оставьте пустым. Откроется прежнее окно с описанием.

Вариант Б: отправьте боту отдельный файл только с условием, обновите админку и выберите его в поле «Файл задания». Кнопка ознакомления отправит этот файл в чат бесплатно.

Не выбирайте платное решение в поле «Файл задания», иначе оно будет выдаваться бесплатно. Если работа содержит несколько вариантов, файл ознакомления должен содержать общие условия/все варианты: кнопка использует первый назначенный файл задания группы.

## 9. Поддержка

1. Студент отправляет вопрос в миниаппе или пишет боту.
2. Бот присылает вопрос вам в личный чат.
3. На этом сообщении нажмите «Ответить».
4. Напишите ответ. Бот передаст его студенту.

Для проверки используйте второй Telegram-аккаунт: сообщения владельца обрабатываются как административные.

## 10. Оплата — отдельная проверка перед продажами

В админке выбираются «Платно» и целое количество Stars. Пока цена пустая, оплата отключена. Рубли автоматически в Stars не переводятся.

До публичных продаж ещё нужно добавить условия покупки и подтверждение согласия в приложении; этот механизм пока не реализован. Затем проверить сценарии в тестовом Telegram-окружении и на целевом сервере: оплата, выдача, повторное получение, отмена и возврат. Локальные автоматические тесты не заменяют проверку настоящего Telegram.

Для регулярных продаж рекомендуем сервер без засыпания. Бесплатный Render может просыпаться около минуты, а Telegram ждёт ответ на pre-checkout до 10 секунд.

Если у старой версии были незавершённые платежи YooKassa, сначала сверить их в кабинете и вручную закрыть обязательства. Новая версия старые уведомления YooKassa не обрабатывает.

Документация: https://core.telegram.org/bots/payments-stars
Ограничения Render Free: https://render.com/docs/free

## Если что-то не заработало

| Симптом | Что проверить |
|---|---|
| Startup failed: Set DATABASE_URL | На Render не сохранена строка подключения Neon |
| Ошибка подключения к базе | Скопирована ли вся строка, существует ли проект Neon, не исчерпаны ли лимиты |
| Invalid webhook secret | TELEGRAM_WEBHOOK_SECRET должен содержать минимум 32 разрешённых символа |
| Бот не отвечает | Статус сервиса Render, Logs, правильность BOT_TOKEN, не работает ли старая копия бота |
| Нет кнопки «Админка» | Вы отправили /start именно с @AxmIldan; ADMIN_USERNAME без @ |
| Админка требует открыть Telegram | Откройте её кнопкой бота, не прямой ссылкой в обычном браузере |
| Материал показывает «Скоро» | Не выбран файл или для платного материала не назначена цена |
| Сохранение прошло, каталог старый | Закройте и заново откройте миниапп: каталог загружается при открытии |
| После простоя всё открывается медленно | Это засыпание бесплатного Render |
| Новый документ не виден | Отправьте его именно боту с аккаунта владельца, затем нажмите «Обновить» |

При обращении за помощью достаточно названия ошибки из Logs. Не присылайте BOT_TOKEN, DATABASE_URL и TELEGRAM_WEBHOOK_SECRET.
