# Помощник — Telegram Web App + Bot с оплатой через ЮMoney

Коротко: готовый минимальный проект, который служит Telegram Web App (frontend `index.html`) и бэкендом на Node.js (`server.js`). Функции:

- показывать каталог (файлы в `catalog.json`)
- формировать ссылку на оплату через ЮMoney (/create-payment)
- принимать нотификации от ЮMoney (/webhook) и отправлять оплаченный файл через Telegram-бота

Быстрый старт локально

1. Скопируйте `.env.example` в `.env` и заполните значения.
2. Установите зависимости:

```bash
npm install
```

3. Запустите сервер:

```bash
npm start
```

Развёртывание на Render

1. Создайте новый Web Service в Render, выберите GitHub-репозиторий.
2. В настройках сервиса укажите команду `npm start` и порт `PORT` (по умолчанию Render выставляет переменную окружения PORT автоматически).
3. В разделе Environment -> Environment Variables добавьте: `BOT_TOKEN`, `YOO_WALLET`, `YOO_SECRET`, `APP_URL` (пример `https://your-app.onrender.com`).
4. (Опционально) если хотите использовать Telegram webhook вместо polling, укажите `TELEGRAM_WEBHOOK_URL` и настройте вебхук у Telegram.
5. В личном кабинете ЮMoney настройте URL нотификаций (Notification URL) на `https://<ваш-домен>/webhook`.

Интеграция с Telegram

- `index.html` — это Telegram Web App интерфейс. `BACKEND_URL` по умолчанию использует `window.location.origin`, поэтому удобно хостить фронтенд и бэкенд на одном домене.
- Бот использует `node-telegram-bot-api`. По умолчанию приложение запускает бота в polling режиме. Чтобы переключиться на webhook, укажите `TELEGRAM_WEBHOOK_URL` в переменных окружения и пропишите этот URL у Telegram.

Тестирование оплаты локально (симуляция)

1. Установите зависимости: `npm install`.
2. Скопируйте `.env.example` в `.env` и заполните `YOO_SECRET` (можно временно любое значение для теста).
3. Запустите сервер: `npm start`.
4. Запустите симулятор нотификации:

```bash
node scripts/simulate_payment.js http://localhost:3000 1002 12345678
```

Скрипт сформирует `sha1_hash` и отправит POST в `/webhook`. Сервер обработает платёж и создаст временную ссылку, которую он попытается отправить в чат (боту нужен рабочий `BOT_TOKEN`, иначе отправка упадёт с ошибкой, но запись об оплате сохранится в `payments.json`).

Безопасность

- Не храните секреты в репозитории — используйте переменные окружения в Render/GitHub Secrets.
