# Google Диск: хранение оригиналов и перенос файлов в бота

## Что уже работает

В текущей версии Google Диск не подключён к программе автоматически. Он хранит ваши оригиналы и резервные копии. Для продажи вы один раз отправляете копию документа боту и выбираете её в админке. Студент получает вложение в Telegram.

Ни настройки Google Cloud, ни сервисный аккаунт, ни ключи Google API для этого способа не нужны.

## Шаг 1. Создать папки

1. Откройте https://drive.google.com под своим Google-аккаунтом.
2. Нажмите «Создать» → «Папку».
3. Назовите её «Материалы приложения».
4. Внутри можно организовать папки так:

```text
Материалы приложения
└── 1 курс
    └── 1 семестр
        └── Высшая математика
            └── Домашнее задание 1
                ├── Условие.pdf
                ├── Решение — вариант 2.docx
                └── Решение — вариант 18.docx
```

Это пример организации. Программа не читает названия папок — каталог пока заполняется в админке.

## Шаг 2. Загрузить документы

На компьютере откройте нужную папку Диска и перетащите туда документы либо нажмите «Создать» → «Загрузить файлы».

На телефоне откройте приложение Google Диск, выберите папку и воспользуйтесь кнопкой «+» → «Загрузить» (названия могут немного отличаться).

Дождитесь окончания загрузки. Давайте файлам понятные названия: предмет, работа, вариант. Так их проще выбрать в админке.

## Шаг 3. Оставить платные материалы закрытыми

1. Откройте настройки общего доступа папки/файла.
2. Для общего доступа выберите «Доступ ограничен» / Restricted.
3. Не включайте «Все, у кого есть ссылка» для платных решений.
4. Проверьте также доступ родительской папки: права могут наследоваться.

Для текущей выдачи через Telegram открывать доступ боту на Диске не требуется. Исходная старая версия раскрывала прямые ссылки: если файлы уже были общедоступны, проверьте их права отдельно.

Справка Google: https://support.google.com/drive/answer/2494822?hl=ru

## Шаг 4. Передать документ в приложение

На компьютере:
1. Если оригинал ещё есть на компьютере, используйте его.
2. Если документ есть только на Диске, нажмите по нему правой кнопкой → «Скачать».
3. Откройте чат со своим ботом в Telegram.
4. Отправьте скачанный документ вложением.
5. Откройте «Админка» → «Обновить».
6. Выберите работу, назначьте документ в поле «Файл решения» и сохраните.

На телефоне:
1. Сохраните файл из Google Диска на устройство или воспользуйтесь отправкой копии в Telegram.
2. В Telegram выберите своего бота и отправьте именно документ.
3. Убедитесь, что в чате появился файл, а не текстовая ссылка на drive.google.com.
4. Выберите файл в админке так же, как на компьютере.

Если работа создана как Google Документ/Таблица, сначала экспортируйте её в обычный файл, например PDF, DOCX или XLSX. Ссылку на редактируемый Google Документ программа документом не считает.

## Шаг 5. Если вы исправили решение

1. Сохраните исправленный оригинал на Диске.
2. Отправьте новую версию боту.
3. В админке нажмите «Обновить».
4. Замените выбранный файл решения и сохраните.

Новые покупки получат новую версию. Уже созданные заказы сохраняют документ, который был назначен в момент покупки. Автоматической рассылки исправлений старым покупателям сейчас нет.

## Ограничения

- Бесплатное место Google-аккаунта общее для Диска, Gmail и Фото; проверяйте доступный объём в своём аккаунте.
- Изменение/удаление оригинала на Диске не обновит/не удалит копию в Telegram.
- Удаление файла из чата не следует считать надёжным способом отозвать ранее выданные документы.
- Резервная копия документов не заменяет резервную копию базы Neon: в базе находятся покупки и настройки каталога.

## Если нужна полностью автоматическая работа с Диском

Сценарий «положил документ в папку Диска — он появился в админке» пока не реализован. Для него нужна дополнительная интеграция с Google Drive и авторизованный доступ приложения к выбранной папке. Публиковать все файлы по открытым ссылкам для этого не нужно.

Можно будет сохранить ту же выдачу в чат: приложение заберёт документ с закрытого Диска, передаст его в Telegram и запомнит идентификатор. Инструкция выше описывает уже реализованный ручной перенос.
